# ZengDeck releases

Downloads for **ZengDeck** — turn your iPhone into buttons, dials, faders, jog wheels and touch bars for your Mac, Windows PC or Linux box.

Get it at **https://zengbot.com/deck** · Free dev preview.

This repository only hosts release files. Each release lists SHA-256 checksums.

Linux: the AppImage runs on most distros (`chmod +x` it first). For keyboard input on Wayland compositors without the remote-desktop portal, install `99-zengdeck-uinput.rules` from the release into `/etc/udev/rules.d/` and add yourself to the `input` group.
